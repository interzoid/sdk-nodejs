# Changelog

## 1.2.7 (2024-10-05) 
### Features
- Added support for additional algorithms for Company and Address Matching. Please see the [README.md](README.md) for more information.
- Deprecated the `csvUrl` parameter in the `DelimitedFileMatchKeyReportRequest` class. Please use the `fileUrl` parameter moving forward. `csvUrl` will be removed in a future release.
- Started using the `CHANGELOG.md` file to document changes to the project.
- Updated dependencies to the latest versions.
- Updated documentation in README.md.
